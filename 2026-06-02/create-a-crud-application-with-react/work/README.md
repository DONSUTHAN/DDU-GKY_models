# CRUD App

Simple full-stack CRUD example with:

- React frontend
- Node.js + Express API
- MongoDB database

## API

- `POST /api/posts/createpost`
- `GET /api/posts/allposts`
- `PUT /api/posts/updatepost/:id`
- `DELETE /api/posts/deletepost/:id`

## Run

1. Copy `work/backend/.env.example` to `work/backend/.env`
2. Copy `work/frontend/.env.example` to `work/frontend/.env`
3. Install dependencies in `work/backend` and `work/frontend`
4. Start backend on port `3000`
5. Start frontend on port `5173`
